# 📊 Data Analysis Projects

This repository showcases a set of **practical data analysis projects** built to explore real-world datasets and extract actionable insights using **Python and Excel**.

Each project is organized in its own folder and includes the **full analysis code and the dataset**, following a clear and reproducible workflow.

---

## 📁 Projects Included

### 🧩 Customer Segmentation – RFM Analysis
Analyzed customer behavior using **Recency, Frequency, and Monetary (RFM)** metrics to segment customers into meaningful groups.  
This type of analysis is commonly used in marketing and retention strategies to identify high-value and at-risk customers.

📂 `customer-segmentation-rfm/`

---

### 📈 Sales Time Series Analysis
Performed a time-based analysis of sales data to uncover **trends, patterns, and seasonality**.  
The project focuses on understanding how sales evolve over time and how such insights can support forecasting and decision-making.

📂 `sales-time-series-analysis/`

---

### 🚢 Exploratory Data Analysis – Titanic Dataset
Conducted an **exploratory data analysis (EDA)** on the Titanic dataset, including data cleaning, visualization, and insight generation.  
The analysis highlights relationships between passenger features and survival outcomes.

📂 `titanic-eda/`

---

### 📊 Excel Dashboard & Reports
An Excel workbook containing **four sheets**, including an **interactive dashboard** that summarizes key findings and metrics from the analyses in a clear, visual format.

📂 `\excel-sales-dashboard/`

---
